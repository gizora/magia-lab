# マギア・ラボ — 科学のことばで魔法をつくる 3D ゲーム

「燃焼」「結合」「屈折」など、化学・物理の単語を 2〜4 個並べて魔法をつくり、練習場で実際に放つ一人称 3D ゲームです。
どんな魔法になるかは**放ってみるまでわかりません**。初めて放った瞬間に、魔法の名前（漢字と読み）が明かされます。

## いちばん手軽な遊び方（公開サイト）

**https://gizora.github.io/magia-lab/** を Edge か Chrome（PC）で開くだけで遊べます。インストールも zip も要りません。
- ゲームを更新すると、公開サイトもそのまま新しくなります。友達はページを開き直す（F5）だけで、いつも最新版で遊べます。対戦するときは、全員が同じ版になるように、開く前に一度 F5 を押してください。
- https で開くので、本物の物理・エフェクトが有効になり、マイクの許可も一度押せば覚えます（start.bat で開いたときと同じ）。
- **セーブデータは、開いた場所ごとに別々に保存されます。** 公開サイト・index.html を直接開いた場合・start.bat の3つは、それぞれ別のデータです。今までのデータを公開サイトへ移すには、いつも遊んでいる版でメニューの「セーブデータ」→「**書き出す**」を押してファイルを作り、公開サイトのメニューで「**読み込む**」を押してそのファイルを選びます（今のデータは上書きされます）。別のパソコンへ移すときや、念のための控えにも使えます。
- 公開サイトは GitHub Pages（無料）に置いています。URL を知っている人なら誰でも遊べ、ゲームのファイルも GitHub で公開されています。

## 遊び方（ダウンロードした版）

1. **`start.bat` をダブルクリック**する（おすすめ）。黒い画面が開き、ブラウザで `http://localhost:8765/` が開きます。黒い画面を閉じるとゲームも止まります。
   - start.bat から開くと、**本物の物理（Jolt Physics）とエフェクト（Effekseer）**も有効になります（タイトル画面に状態が出ます）。
   - `index.html` を直接開いても遊べますが、物理とエフェクトはオフ（簡易版の動き）になり、またブラウザがマイクの許可を覚えないため、声で唱えるときに**聞き取りが止まるたびに V キーで聞き直し、そのつど許可を聞かれます**。start.bat から開けば、最初に一度「許可」を押すだけで、自動で聞き続けます。
   - start.bat には Node.js が必要です（この PC には入っています）。インストールは不要で、ネット接続も「声で唱える」とき以外は不要です。
2. 「はじめる」を押す。**村**から始まります。画面をクリックすると、マウスで視点を動かせるようになります。
3. **E キー**（または右上の「魔法工房」）で工房を開き、単語を並べてスロット 1〜4 に登録する。
4. **クリック**して放つ。初めて放った魔法は、その場で名前が明かされ、図鑑に記録されます。
5. 村の門から**練習場**（的がある）や**ダンジョン**へ行けます。ダンジョンで経験値とお金をためてレベルを上げ、杖を買い、深い階をめざします（「村とダンジョン」）。

| 操作 | キー |
|---|---|
| 移動 / 走る | WASD（矢印キー） / Shift（歩き 5.2m/秒・走り 8m/秒。走る・跳ぶとスタミナが減る） |
| 視点・ねらい | マウス |
| 魔法を放つ（スロット・無詠唱） | 左クリック（長押しで連射）、F / Q（F は入れる場所の近くでは「入る」、Q はダンジョンでは「回復薬」） |
| 神殿・杖の店・門・下の階・帰還ポータルに入る | 近づいて F |
| 回復薬を飲む（ダンジョンの中） | Q |
| 魔法の切り替え | 1〜（杖のスロット数）、マウスホイール、スロットをクリック |
| 杖をえらぶ | T（または右上の「杖」ボタン、メニュー） |
| 友達とパーティー | タイトルかメニューの「友達とパーティー」。ダンジョンで倒れた仲間のそばでは F を4秒長押しで蘇生 |
| 友達と対戦 | タイトルの「友達と対戦」、またはメニューの「友達と対戦」 |
| ジャンプ | Space（約 1.85m。木箱・2段の石壁・小さめの岩に跳び乗れる） |
| 飛翔の魔法で飛んでいる間 | Space で上昇、C で下降（何も押さなければその高さにとどまる） |
| 魔法工房 / 図鑑 / メニュー | E / G / **Tab**（もう一度押すと閉じる） |
| マウスの固定を外す（一時停止） | Esc（「一時停止中」の小さな画面が出る。画面をクリックで戻る。メニューは Tab） |
| 昼と夜の切り替え | N（または右上のボタン） |
| 声で唱える（マイク）のオン・オフ | V（または右上の「詠唱」ボタン） |
| 紋章を描く | 右クリックを押しながらマウスを動かす（離すと読み取る。少し押すだけで最後の紋章を1つ消す） |
| 全画面 | 右上の「全画面」ボタン（メニューからも。F11 キーでも可） |
| 音のオン・オフ | M |

**PC（マウス＋キーボード）専用**です。スマホでの利用は想定していません（タッチ操作のコードは残っていますが、確認はしていません）。

## 魔法のしくみ

同じ単語でも、**置く場所で役割が変わります**。

| 位置 | 役割 | 例（燃焼） |
|---|---|---|
| 1番目 | 属性（色・特徴） | 炎属性（燃やす） |
| 2番目 | 形（飛び方） | 砲弾（弧を描いて爆発） |
| 3・4番目 | 効果 | 灼熱（燃やし続ける） |

- 単語は 34 語（化学 15・物理 19）。属性 20 種、形 19 種、効果 34 種。
  - 「強化」（1番目: 力属性 / 2番目: 連弾 / 3・4番目: 威力1.3倍と貫通力+1）、「真空」（真空属性 / 渦 / 的を強く吸い寄せる）、「回帰」（時属性 / 連鎖 / 少しあとに同じダメージをもう一度）
- **守り・回復・移動のことば**（第15版で追加。2番目に置くと、攻撃ではなく自分を助ける魔法になります）
  | ことば | 1番目（属性） | 2番目（形） | 3・4番目（効果） |
  |---|---|---|---|
  | 遮蔽 | 磁 | **障壁**: 自分のまわりに、ダメージを吸い取る障壁を 6 秒張る（吸収量 60 が基準）。こわれると、まわりに属性の衝撃を放つ | **守護**: 放ったあと 3 秒間、受けるダメージが半分 |
  | 再生 | 霊気 | **再生**: HP を 45 回復（6 割はすぐ、残りは 3 秒かけて）し、燃焼・凍結・腐食を消す | **吸命**: 相手に与えたダメージの 30% だけ HP が回復（対戦のとき） |
  | 転移 | 魔素 | **転移**: 狙った場所（最大 24m）へ一瞬で移り、着いた場所に衝撃を放つ。壁・柱・岩の手前で止まり、相手を狙うと相手の目の前に降りる | **瞬身**: 放つと同時に、狙いと反対へ 5m 跳び退く |
  - 例: 燃焼→遮蔽 =「炎盾（フレア・シールド）」、凝固→再生 =「氷癒（アイス・ヒール）」、放電→転移 =「雷転（ボルト・ワープ）」。属性で色と、障壁がこわれたとき・転移で着いたときの衝撃の性質（燃やす・凍らせる など）が変わります。
- **飛ぶ・降らせる・まとうことば**（第20版で追加）
  | ことば | 1番目（属性） | 2番目（形） | 3・4番目（効果） |
  |---|---|---|---|
  | 揚力 | 風 | **飛翔**: 16 秒間、空を自由に飛べる（Space で上昇・C で下降、地面から 32m まで。横の速さ 1.3 倍）。時間が切れると、ゆっくり降りて着地する | **浮遊**: 放つと同時に、上へ高く跳び上がる |
  | 衝突 | 岩 | **流星**: 狙った場所の上空（26m）に魔法陣を描き、0.8 秒後から大きな流星（燃える岩）を 3 つ落とす。1 つ 40 の爆発（半径 5m）で、地形も壊す | **粉砕**: 威力 1.2 倍。岩や壁などの地形も壊せるようになる |
  | 帯電 | 雷 | **纏い**: 7 秒間、属性の力を体にまとう。足が速くなり（属性しだいで約 1.2〜1.65 倍。雷はとくに速い）、まわり 3m の的に 0.5 秒ごとに少しずつダメージを与える | **迅速**: 放ったあと 4 秒間、足が 1.35 倍速くなる |
  - 例: 加速→揚力 =「風翼（ウィンド・ウィング）」、燃焼→衝突 =「炎流星（フレア・メテオ）」、放電→帯電 =「雷纏（ボルト・オーラ）」（雷をまとって 1.65 倍の速さ）。
  - 対戦では、相手が飛んでいると背中に光の翼が見え、纏いを使っていると体が属性の色に光ります（雷なら小さな稲妻が走る）。相手の流星の魔法陣も上空に見えます。纏いのダメージは相手にも当たります。
  - 自分が纏いを使っている間は、画面のふちが属性の色に光ります（雷なら細かく明滅）。画面下に、飛翔・纏い・迅速の残り時間が出ます。
- **召喚のことば「合成」**（第22版で追加）
  | ことば | 1番目（属性） | 2番目（形） | 3・4番目（効果） |
  |---|---|---|---|
  | 合成 | 霊気 | **召喚**: 1番目の属性に合った召喚獣を呼び出し、15 秒間いっしょに戦わせる | **使い魔**: 放つと小さな使い魔（光の玉）が現れ、10 秒間そばを飛びながら近くの敵を小さな弾で撃つ |
  - 召喚獣の種類は1番目の属性で決まります。
    | 種類 | 属性 | 動き | HP |
    |---|---|---|---|
    | ゴーレム | 岩・鋼・晶・力・磁 | 重くて固い。歩いて近づき、太い腕で殴る（威力が高い） | 150 |
    | 精霊 | 炎・氷・雷・プラズマ・光・虚空・霊気・魔素・虹・蒸気 | 宙に浮かび、少し離れた所から属性の弾を撃つ | 70 |
    | 獣 | 風・音・時・真空・酸 | すばやく走り、飛びかかってかみつく | 90 |
  - 例: 結合→合成 =「岩像（ロック・ゴーレム）」、燃焼→合成 =「炎精（フレア・スピリット）」、加速→合成 =「風獣（ウィンド・ビースト）」。
  - 召喚獣の攻撃には、属性の力（燃やす・凍らせる・吹き飛ばす など）と、3・4番目の効果が宿ります。屈折（多重）で 2 体、結合（巨大）・膨張で大きく HP も多く、加速（神速）ですばやくなります。
  - 一度に出せるのは 3 体まで（4 体目を呼ぶと、いちばん古いものが消えます）。使い魔は 1 体まで。近くに敵がいないときは、自分の横に控えます。岩や壁にぶつかったら、横へ回りこみます。
  - 自分の魔法は自分の召喚獣に当たりません。対戦では、相手の画面にも召喚獣が見え、相手の魔法で倒されることもあります。画面下に、召喚獣の HP と残り時間が出ます。足もとの魔法陣（召喚紋）が目印です。
- **障壁の形**（第22版）: 「遮蔽」を2番目に置いた障壁は、**1番目の属性**と**3・4番目の効果**で形が変わります。
  | 形 | どうすればなるか | はたらき |
  |---|---|---|
  | 球 | 下のどれにも当てはまらない属性（炎・雷・霊気 など） | 今までどおり、自分のまわりを包み、どの方向からのダメージも吸い取る（吸収量 60 が基準） |
  | 大盾 | 1番目が力・磁・音・光、または 3・4番目に圧縮（凝縮） | 体の前に大きな盾を構える。**前から**来たダメージだけを、球の 1.6 倍吸い取る（後ろや横からは防げない） |
  | 壁 | 1番目が岩・鋼・氷・晶 | 目の前（約 3m 先）に壁（幅 5m・高さ 2.8m）を立てる。その場に約 8 秒残り、相手の弾・光線を止める。**上に乗ることもできる**。吸収量の 1.5 倍の HP |
  | 城壁 | 3・4番目に屈折（多重） | 前と左右ななめに 3 枚の壁を立てて、自分を囲む |
  | ドーム | 3・4番目に拡散（広域） | その場に半径 4.5m の半球のドームを張る。外から来た相手の弾・光線を止める（自分の魔法は内側から外へ通る）。吸収量の 2 倍の HP |
  - 3・4番目の効果の決まりが先に効きます（例: 岩でも、拡散を付ければドーム）。結合（巨大）・膨張（膨大）・発光（光輝）で壁やドームが大きくなります。
  - 例: 凝固→遮蔽 =「氷壁（アイス・ウォール）」、強化→遮蔽 =「剛大盾（フォース・イージス）」、結合→遮蔽→屈折 =「多岩城壁（マルチ・ロック・フォート）」、燃焼→遮蔽→拡散 =「広炎天蓋（ワイド・フレア・ドーム）」。
  - 壁とドームは、立てた人の魔法を通し、ほかの人の魔法を止めます（爆風も壁の HP を削ります）。HP が 0 になると砕けて、属性の衝撃を放ちます。対戦では、相手の画面でも同じ場所に立ちます。
  - 岩・鋼・氷・晶の壁は「物」の見た目（岩肌・金属・透きとおった氷・結晶）、それ以外は六角形の網目が光る壁になります。
  - **障壁の見た目**: 相手からは、属性の色の六角形の網目が光る球に見えます（ふちが明るい）。当たると、当たった所が白く光って波紋が広がります。残りが少ない（35% 未満か、残り 1.2 秒未満）と、ひびの入ったマスが点滅します。こわれると、ガラスのように砕けて破片が飛び散ります。自分の画面では、画面のふちに属性の色の網目が出て、当たると強く光り、残りが少ないとひびが入って点滅し、こわれると砕けて消えます。
  - 練習場では自分の HP が減らないので、再生は回復の数字が出るだけです。障壁・守護・再生中は、画面下の MP の上に残りが表示されます。
- **放つまでわからないこと**: 工房で見えるのは、並べた単語とその役割（属性・形・効果）だけです。名前・威力・消費 MP・範囲・待ち時間は「？？？」と表示され、初めて放った瞬間にわかります。
- **威力は実測**: 図鑑と工房の「最大ダメージ」は、その魔法を1回放ったときに実際に的に与えたダメージの最高記録です。
- **隠し魔法（禁呪）が 17 個**あります（第24版で 8 個、第25版で 1 個追加）。決まった順番で並べて放ったときだけ「隠し魔法を発見！」と出ます（放つ前の工房では、ふつうの魔法と区別がつきません）。図鑑にヒントが出ます。
  - 第24版で追加した 8 個（並びは遊ぶ人が見つけるものなので、ここには書かない。答えは js/words.js の MG.SECRETS）。図鑑のヒントは、答えのことばを使わずに現象だけをほのめかす書き方にしています。
    - **電磁加速砲**: 磁場のリングで 0.6 秒ためて、壁も的もすべてつらぬく閃光を一直線（100m）に撃つ。石壁などは壊れる。
    - **大地震**: 自分のまわり 25m の大地を 3 秒揺らし、地面にいる的に 0.5 秒ごとにダメージ（合計 120）。壁や岩も崩れる。浮遊水晶・精霊・使い魔・跳んでいる人・反磁性で浮いている人には当たらない。
    - **世界樹**: 狙った場所に高さ 20m の光る大樹を 20 秒生やす。まわり 12m の的を 1 秒ごとにつるで打ち（4 体まで）、木から 10m 以内にいると HP（練習場では MP）が回復する。
    - **巨神像**: 黒い鎧に金のふち・赤いマント・背中の光輪の巨神（HP 600、25 秒）を呼ぶ。両腕で大地をたたき、まわり 5m の敵をまとめて打つ。ふつうの召喚獣（3 体まで）とは別に 1 体だけ。
    - **不死鳥**: 炎の鳥が狙った方向へまっすぐ飛び、大きく旋回して戻ってくる。通り道の的を焼き（燃焼つき）、戻ってきたら HP 60（練習場では MP 40）回復。
    - **時間遅延**: 狙った場所に半径 10m の時の球を 8 秒張る。中では、張った人以外の的・召喚獣・弾が 1/5 の速さになり、相手は歩く速さと魔法の待ち時間も遅れる。
    - **完全反磁性**: 15 秒のあいだ少し浮かび（大地震・柱が当たらない）、まわり 3m に入った相手の弾を撃った人へはね返し、近づいた敵を押し返す。光線は半分だけ防ぐ。
    - **千刃の門**（第25版）: 背後から左右の空中に鋼の魔法陣を 14 個開き、剣・槍・斧を 2.6 秒のあいだ雨のように撃ち続ける（1 本 14 ダメージ、ねらった相手を追う）。外れた武器は地面や壁に突き刺さり、少しして消える。
    - **賢者の石**: 狙った場所に赤い石を生み、まわり 9m を黄金に変える。HP 150 以下の的は黄金になって砕け（得点 2 倍）、それより強い的には 120 ダメージ。
  - 対戦では、強い隠し魔法の相手プレイヤーへのダメージを下げています（電磁加速砲 ×0.55、大地震・世界樹・巨神像 ×0.6、不死鳥 ×0.8、賢者の石 ×0.5、千刃の門 ×0.35）。
  - 例: 強化→圧縮→真空→回帰 =「消滅領域」: 少し離れた場所（ねらった場所。近すぎ・遠すぎのときは約 14m 先）に透明な球体を生み、その内部にあるものを、的も地形も地面も跡形なく消し去ります。地面は球の形にえぐれ、発動中は BGM が遠のきます。
- **貫通力**: 魔法が壁を何枚つらぬけるか。光線は生まれつき 2 枚、効果の「貫通」で +2、「凝縮」「神速」「重撃」で +1、鋼属性で +1。貫通力が残っている弾や光線は、岩・石壁・木箱・石柱をすり抜け、残っていなければ止まります。図鑑と工房には、実際につらぬいた最大枚数（実測）を記録します。
- **名前**は「効果（1字ずつ）＋属性（1字）＋形」の短い漢字と、カタカナの読みで作ります。
  - 例: 燃焼→慣性 =「炎砲弾（フレア・キャノン）」、放電→重力→燃焼 =「灼雷渦（バーン・ボルト・ボルテクス）」、凝固→結晶→加速→磁力 =「速追氷雨（クイック・ホーミング・レイン）」
  - 属性の字（炎・氷・雷・闇…）、形の字（弾・砲弾・散弾・槍・鎖・雨・柱・霧・渦・環・球・連弾）、効果の字（灼＝燃やす、速＝神速、追＝追尾、貫＝貫通…）はそれぞれ1つに決めてあるので、名前を見れば中身の見当がつきます。
  - 効果が2つ付いて読みが4語になるときや、読みが 12 字を超えるときは、属性の読みを省いて短くします（例:「巻闇渦」は「リワインド・ボルテクス」）。名前は最長でも漢字5字・読み3語です。
  - 同じ並びなら必ず同じ名前になり、並びを変えると名前も変わります。性能は「属性・形・効果」だけで決まるため、別の単語の並びでも中身が同じ魔法は同じ名前になります。

- **見た目**: 杖ごとに形がちがい、色を見なくても区別できます（宝石は、選んでいるスロットの魔法の色に光ります）。対戦では、相手が持っている杖も同じ形で見え、素手の相手は両手が光ります。

  - 破壊の杖: 黒く太い柄に鉄の輪、先に赤いとげ 4 本と大きな宝石
  - 賢者の杖: 長い白木に緑のつるが巻きつき、先に金の輪と葉

## 友達とパーティー（第39版・インターネット越し・最大4人）

タイトルかメニューの「**友達とパーティー**」から、友達と一緒に村とダンジョンを進めます。料金はかかりません。

### 集まり方
1. 1人が「パーティーを作る」を押す（リーダー）。合言葉が出る。
2. 友達は「パーティーに入る」で合言葉を入れる。つながらないときは、予備の招待コード・返事コードも使える。
3. 仲間一覧（名前・Lv・杖）で全員が「準備完了」を押すと、リーダーが出発できる。

全員が同じ版で遊ぶ必要があります。古い画面が残っているときは、ページを再読み込みしてください。

### 決まり（ユーザーが選んだもの）

| 項目 | 決まり |
|---|---|
| 編成 | 役割はなし。強さは今のレベルと杖で決まる |
| 一緒の場所 | 村とダンジョン。練習場と、店・神殿の画面は各自 |
| 蘇生 | 倒れた仲間のそばで F を4秒押し続けると HP 40% で復活。何も消費しない。押している間は動けず魔法も使えない。攻撃を受けると中断 |
| 全滅 | 全員が倒れると、拾った物とその回の経験値を失う |
| 分け方 | お金と経験値は、与えたダメージの割合で分ける。宝箱は開けた人のもの |
| 階の移動 | 下の階へは全員集合。帰還は各自で、帰った人はそこで探索終了、残りは続行 |
| 難しさ | 敵の HP だけ増える（1人増えるごとに +60%、守護者 +80%）。数と攻撃力は同じ。味方の魔法は味方に当たらない |
| リーダーの通信切れ | 全員がそこまでの成果を持って帰還 |
| メンバーの通信切れ | 残った人で続行 |
| 途中で閉じた・再読み込み | 今の階の最初から再開。パーティーだった場合はひとりで再開 |

### Claude が判断したこと
- **倒れた仲間がいる間は下の階へ進めない**（「全員集合」を、残っている全員が立って穴に集まること、と解釈した）。
- **立っている人が全員帰還して、倒れた人だけが残ったら全滅**。
- **守護者の大地たたきは、輪の中にいる人全員に当たる**。
- **パーティー中はメニューを開いても時間が止まらない**（入力だけ止まる）。
- **探索中のパーティーには途中から入れない**。パーティーと対戦の部屋には同時に入れない。
- **パーティーに入っている間は、ひとりでダンジョンに入れない**（抜ければ入れる）。

### しくみと限界
- 通信はリーダーが中継する。敵は、ダンジョンに残っている人の先頭の画面で動き、その人が帰ると次の人に移る。だからリーダーが先に帰っても続けられる。ただし、リーダーがページを閉じると全員の探索が終わる。
- 描画が止まっても（別のタブを見ているなど）、Worker の時計で世界を進める。
- 倒れて蘇生を待つ間に再読み込みすると、決まりどおり今の階の最初からひとりで再開する（＝蘇生なしで戻れる）。
- リーダーとの通信切れと、自分の回線を切ったことは区別できない。どちらも持ち帰りになる。
- 友達どうしで遊ぶ前提のため、改造した画面による不正までは防がない（受け取った数は範囲に収めている）。

## 友達と対戦（インターネット越し・最大4人）

タイトル画面かメニューの「**友達と対戦**」から、離れた場所の友達と魔法で撃ち合えます。料金はかからず、ゲーム用のサーバーも使いません（対戦のデータは、ブラウザどうしを WebRTC で直接つないでやりとりします）。対戦は、練習場ではなく**闘技場**で行います。

### つなぎ方（合言葉）
1. ひとり（ホスト）が「**部屋を作る**」を押すと、「くじら-7126」のような**合言葉**が出る。LINE や Discord で送っても（「コピー」で誘いの文ごとコピーできる）、通話で口で伝えてもよい。
2. 友達は「**部屋に入る**」で合言葉を入れて「**入る**」を押すと、つながる。3人目・4人目も同じ合言葉で入れる。
3. ホストが勝ちの条件（3・5・10人倒す）と制限時間（3・5・10分）を選んで「**対戦開始**」。

- 合言葉は「ことば＋4けたの数字」です。カタカナや全角の数字で入れても、「-」を省いても通ります。
- **合言葉は自分で決めることもできます**: ロビーの最初の画面の「合言葉（自分で決める場合）」の欄に入れてから「部屋を作る」を押します（空欄なら自動）。部屋を作ったあとも、友達がつながる前なら「合言葉を変える」で変えられます（「自動で決める」で自動の合言葉にも戻せます）。
  - ひらがな・カタカナ・漢字・英数字の 2〜24 文字。カタカナとひらがな、全角と半角、英字の大文字と小文字、空白や「-」は区別しません（例:「マギアのへや」と「まぎあの へや」は同じ部屋）。
  - 同じ合言葉の部屋がすでに開いているときは「ほかの部屋で使われています」と出るので、別の合言葉にしてください。短すぎる合言葉は、知らない人に当てられて入られることがあります。
  - つなぎ役のサーバーには、合言葉そのものではなく、合言葉から計算した記号の列（部屋の番号）だけを渡します。
- **全員が同じ版のゲーム**を使ってください。版がちがうと、同じ合言葉でも部屋が見つかりません。
- 対戦中の部屋には、合言葉で入れません（「対戦中です」と出ます）。対戦が終わってロビーに戻れば入れます。

### 予備のつなぎ方（コード）
合言葉でつながらないとき（つなぎ役のサーバーが止まっているときなど）は、ロビーの「**合言葉でつながらないとき: コードで招待する（予備）**」を開きます。
1. ホストが「招待コードを作る」を押し、できた長いコードを友達に送る。
2. 友達は「部屋に入る」→「招待コードをもらったとき」でそのコードを貼り付け、できた**返事コード**をホストに送り返す。
3. ホストが返事コードを貼り付けて「つなぐ」を押すと、つながる。合言葉で入った人とコードで入った人がいっしょに遊べます。

- `index.html` を直接開いても、start.bat から開いても使えます（声の詠唱を使うなら start.bat がおすすめ）。
- 3人以上のときは、ホストが全員の通信を中継します。ホストが部屋を閉じると、対戦は終わります。

### 闘技場
- 高い石の壁と階段状の客席に囲まれた、砂の円形の広場（壁の内側の半径 40m）です。門が 4 つ、旗が 8 枚、かがり火が 8 つあります。
- 中には盾にできる地形があります: レンガの壁 4 枚（中央から 17m）、石柱 8 本（27m）、岩 4 つ（9m）、木箱の山 4 つ（31m）。どれも破壊属性の魔法で壊せ、対戦のたびに元どおりになります。
- 復活地点は、壁ぎわの東西南北 4 か所（中央から 33m）です。
- 対戦が終わる（部屋を出る）と、練習場に戻ります。

### ルール
- 自分の図鑑の魔法・杖・素手・声の詠唱・紋章・守り／回復／移動の魔法を、**いつもと同じルール**で使います（隠し魔法も使えます）。
- HP は **200**。倒されると **4 秒後**に、相手からいちばん遠い復活地点で HP・MP 満タンで復活します。復活してから 2.5 秒は「守り」がつき、ダメージを受けません（自分が魔法を放つと守りは消えます）。
- 燃焼（燃え続ける）・凍結（動きが遅くなる）・腐食（受けるダメージが 1.35 倍）・吹き飛ばしも、相手に届きます。
- 先に決めた人数を倒した人の勝ち。制限時間になったら、いちばん多く倒した人（同じなら倒れた回数が少ない人）の勝ち。
- 障壁を張っている相手に当てたダメージは、まず障壁が吸い取ります（障壁が残っている間は、燃焼・凍結・吹き飛ばしも防ぎます）。守護中の相手には半分しか効きません。
- **相手の魔法陣が見えます**: 相手が紋章を重ねている間や、名前を唱えている途中は、相手の目の前に、その魔法の紋章を重ねた魔法陣が浮かびます。紋章を読めば、何を撃ってくるか見当がつきます。放つと魔法陣は広がって消えます。
- 対戦中にメニューや工房を開いても、世界は止まりません（自分は動けなくなるだけ）。

### 画面
- 左上: 全員の倒した数。上: 残り時間。右上: だれがだれを、どの魔法で倒したか。
- 下: 自分の HP と、受けている状態（守り・燃焼・凍結・腐食）。その上に、自分の障壁・守護・再生中。
- 相手は、色ちがいのローブと帽子の魔法使いとして見え、頭の上に名前と HP が出ます。障壁を張っている相手は、属性の色の球に包まれて見えます。

### 送られる情報
- **合言葉でつなぐとき**は、最初の顔合わせ（つなぐのに必要な情報の受け渡し）だけ、無料の公開サーバー **PeerJS**（0.peerjs.com）を使います。受け渡すのは、接続情報（自分の回線の IP アドレスなど）と、合言葉から作った部屋の番号だけです。**名前は渡さず**、直接つながってから部屋のメンバーにだけ送ります。
- 予備の招待コード・返事コードには、**自分の回線の IP アドレス**が入っています。信頼できる友達にだけ送ってください。
- つなぎ先を調べるため、無料の **STUN サーバー**（Google の stun.l.google.com、Cloudflare の stun.cloudflare.com）に問い合わせます。
- つながったあとの対戦の通信（位置・放った魔法・ダメージ）は、友達のブラウザとの間だけでやりとりします。

- Lv1 は 最大HP 150・最大MP 60・MPの回復 10/秒。必要な経験値は Lv が上がるほど増えます（Lv5 まで 620、Lv12 まで約 6200）。
- **ことばの封印**: 最初はことばを **2 語**までしかつなげられません。**Lv5 で 3 語、Lv12 で 4 語**の封印が解けます。前の版で覚えた 3 語・4 語の魔法（隠し魔法も）は、封印が解けるまで放てません（スロットに「封印中」と出ます。図鑑では薄暗く「封印」の札が付き、選べません）。
- 能力は**友達との対戦にも反映**されます（最大HP・最大MP・MPの回復・威力・足の速さ・待ち時間）。

## 練習場

- **地形の上に乗れる**（第22版）: 岩・石壁・木箱・薄い岩壁・石柱・魔法の壁の上に立てます。岩は形に合わせて立ち、石壁は段の上に乗れます。横からぶつかると、めりこまずに面に沿ってすべります。乗っている地形が壊れると落ちます。闘技場の石柱も、すり抜けずに当たるようになりました。
- **的**: 前方に 7 つ横一列で並んでいます（木の的・浮遊水晶・台座の的・石像ゴーレム）。動かず、壊れると同じ位置に復活します。
- **昼と夜**: 右上の「昼にする／夜にする」ボタン、N キー、メニューで切り替えます。空・光・霧がなめらかに変わり、設定は保存されます。
- **破壊属性と地形の破壊**: 砲弾・降雨・宝珠・渦・柱・流星の形の魔法と、効果「粉砕」の付いた魔法、爆発系の隠し魔法（超新星・事象の地平・太陽創造・積乱雷雲・消滅領域・電磁加速砲・大地震）は**破壊属性**を持ちます（放った後に名前と一緒にわかります）。
  - 地面に当たると**クレーター**ができ、焦げ跡が残ります。へこんだ場所にはプレイヤーも的も沈みます。
  - **石壁**（レンガ単位で壊れ、支えを失った上の段は崩れ落ちる）、**岩**（当てるたびに欠けて、最後は砕ける）、**木箱**、**外周の石柱**（倒れる）を壊せます。
  - 壊れた岩・壁・木箱は 25 秒、石柱は 30 秒で元に戻ります。クレーターはメニューの「壊れた地形を元に戻す」で直せます。
  - 破壊属性のない魔法は地形を壊せず、弾は岩や壁に当たって止まります。
- **貫通テスト場**: 練習場の右側に、番号つきの薄い岩壁 6 枚と、一番奥の的があります。手前から奥へ撃つと、壁に「貫通 1」「貫通 2」…と出て、手前の掲示板に「○枚 貫通」と結果が出ます。破壊属性の魔法では壁が壊れ、12 秒で元に戻ります。
- **60秒チャレンジ**（メニューから）: 制限時間内のスコアを競います。最高記録が保存されます。

## 声で唱えて放つ

- **V キー**（または右上の「詠唱」ボタン、メニュー）でマイクをオンにすると、オフにするまで聞き続け、唱えた魔法がその場で放たれます。もう一度 V キーで止まります。
- 音声認識は、しばらく黙っていると自動で止まります。
  - **start.bat から開いたとき**（`http://localhost:8765/`）: 最初に一度「許可」を押せばブラウザが覚えるので、止まっても自動で聞き直し、聞き続けます。
  - **index.html を直接開いたとき**: ブラウザが許可を覚えない仕組みのため、自動で聞き直すと許可を何度も聞かれてしまいます。そこで自動では聞き直さず、「V キーでもう一度」と案内します。
- **唱えるのは魔法の名前だけ**です。一度放って名前がわかった（図鑑にある）魔法の読み（例:「フレア・キャノン」）を唱えます。隠し魔法などは漢字の名前（例:「超新星」）でも唱えられます。名前は図鑑と工房で確かめられます。
  - **杖を持っているとき**: 多少の言い間違い（1字ちがい・1字抜け、前後の余計な言葉）があっても、名前にいちばん近い魔法が発動します。
  - **素手のとき**: 名前を**一字一句そのまま**唱えたときだけ発動します。
  - まだ放っていない魔法は、名前がわからないので唱えられません（スロットか紋章で一度放つと、唱えられるようになります）。ことばを並べて唱える方法は、第15版でなくしました。
  - 読みが同じ魔法が 2 つ以上あるとき（効果が 2 つ付いて属性の読みを省いた名前など）は、今の杖のスロットに入っている魔法 → 最近放った魔法、の順に選びます。
- 聞き取った言葉と結果は画面下に出ます。杖を持って唱えると効果は 30% ダウン、素手で唱えると 50% アップします（くわしくは「杖と素手」）。
- **声の送り先**: ブラウザの音声認識（Web Speech API）を使うため、声はブラウザの提供元のサーバー（Edge は Microsoft、Chrome は Google）に送られます。料金はかかりませんが、インターネット接続が必要です。初めて使うときに、この説明と確認の画面が出ます。

## 紋章を描いて放つ

34 のことばには、それぞれ一筆書きの**紋章**があります（燃焼＝三角、重力＝下へ一直線、結合＝∞、放電＝稲妻、遮蔽＝門（Π）、再生＝e、転移＝C、揚力＝ω、衝突＝右下への矢（↘）、帯電＝α、合成＝Y（左上→まん中→右上→まん中→下） など）。紋章を描いて魔法陣に重ね、**左クリック**で発動します（第15版で、最後に名前を唱える手順をなくしました）。

1. **右クリックを押したまま**マウスを動かして紋章を描き、離す。読み取れた紋章が画面の魔法陣に重なり、目の前の輪が1つ増える。
2. 同じように、2〜4 個の紋章を**ことばの順番どおりに**重ねる（1つ目が属性、2つ目が形、3・4つ目が効果。工房と同じ）。
3. **左クリック**で発動する。まだ一度も放っていない魔法も放てます（放つと名前が明かされます）。紋章を重ねている間の左クリックは、スロットの魔法ではなく紋章の魔法になります。

- 描いている間は、画面の左に 33 個の紋章の一覧が出ます（● が描き始め）。工房のことばの説明と、図鑑の魔法の説明にも紋章が出ます。
- 閉じた形（三角・四角・ひし形・円・星・∞・砂時計）は、どこから描き始めても、どちら回りでもかまいません。それ以外は、一覧の ● から描きます。少し傾いたり、縦横がつぶれたりしても読み取れます。
- 右クリックを少し押すだけ（ほとんど描かない）で、最後に重ねた紋章を1つ消せます。同じ紋章は2回重ねられません。重ねたまま 15 秒たつと消えます。
- **効果**: 杖を持っていても**効果は下がりません**（声の詠唱は 70%）。素手のときは素手のルール（効果 150%・MP 1.6 倍）です。MP と待ち時間は声の詠唱と同じです。
- 友達との対戦でも使えます。重ねている紋章は、相手の画面にも魔法陣として見えます。

## 音と振動

- **音の素材**（第22版）: 炎・氷・雷・プラズマ・光・虹・魔素・霊気・時・晶・蒸気・風・虚空・真空の発動音と、炎・氷・晶・雷・プラズマ・光・岩・鋼・力・虚空・魔素の着弾音に、効果音の素材（「使っている外部ライブラリと素材」）を重ねています。素材の音を重ねるときは、合成した音を小さくして、属性らしい響きを残しています。召喚・障壁・隠し魔法の大爆発・ためる音にも素材を使います。雷の音は、長く鳴り続けると間延びするので、素材を 1.3 秒に切り、発動 0.5 秒・着弾 0.7 秒だけ鳴らします（第23版）。
  - **消滅領域の音を壮大に**: 球が生まれると「収束」の音と、低く落とした詠唱の声（2つ）が重なり、遠くの合唱のような和音と地の底からの低音が、球が閉じる瞬間（約 1.9 秒後）に向かって高まります。球が閉じると、重い衝撃音を 2 つの高さで重ね、地鳴りと澄んだ鐘の余韻が長く残ります。BGM はその間ずっと遠のきます。
  - 素材は js/sfx-data.js に入っているので、index.html を直接開いても鳴ります。
- **BGM**: 練習場では、神秘的な BGM をその場で自動演奏します（Dマイナーの和音がゆっくり移り変わり、やわらかな和音・低い持続音・こだまの残る鈴・きらめき・遠くの合唱のような声を重ねる）。昼は少し明るい音色になります。以前あった環境音（低いうなりと虫の声）はなくしました。メニューで音量とオン・オフを変えられます。
- **属性に合った音**: 17 属性それぞれに専用の発動音・着弾音・命中音があります。残響（ホールのような響き）、音のひずみ、重低音、炎のちらつきのような揺らぎを何層も重ねて迫力を出しています（炎は「ドォン」と爆ぜたあと「ゴオォォ」と燃え広がり、火の粉がパチパチはぜる、など。炎はボッと燃えてパチパチはぜる、氷はガラスが割れる音と鈴の音、雷はバリッと裂ける音と雷鳴、岩はドスンと重い音と転がる石、鋼はカーンと響く金属音、音属性は鐘のように響く、など）。鳴った場所に合わせて左右と音量が変わります。
- **画面の揺れ**: 画面の位置だけでなく、**視点（ねらいの向き）もぶれます**。属性ごとに揺れ方が違います（雷＝細かい小刻み、岩・鋼・虚空＝重いドスン、炎・蒸気・酸＝ゴゴゴと不規則、氷・結晶・光＝一瞬だけ鋭く、風・霊気・虹＝横ゆれ、音・磁・魔素＝リズムで震える）。強さはメニューで「オフ／弱／標準／強」から選べます。
- **ゲームパッドの振動**: Xbox などのゲームパッドをつなぐ（つないだあとボタンを 1 回押す）と、魔法の発動・着弾・壁の貫通に合わせて、属性ごとのパターンで振動します。メニューの「テスト」ボタンで確認できます。PC 本体を振動させる方法はブラウザにないため、振動はゲームパッドだけです。

## 本物の物理とエフェクト（start.bat から開いたとき）

- **物理（Jolt Physics）**: 壊れた地形や的を、重さと衝突のある本物の物理で動かします。
  - 石壁のレンガと木箱は、最初から「眠った物体」として積まれています。爆風で押し飛ばされ、支えを失った上の段は重力で崩れ落ち、がれきとして転がります。崩れた壁は、25 秒後に壁ごと元に戻ります（近くに立っているときは待ちます）。
  - 岩・薄い岩壁・木箱を壊したときの破片、倒れた石柱のブロック、倒した的も、物理で転がってぶつかり合います。
  - クレーターやえぐれた地面は、物理の地面にも反映されます（落ちた破片はくぼみの底で止まる）。
- **エフェクト（Effekseer）**: 魔法の着弾・光線・連鎖・渦・衝撃の輪・隠し魔法に、属性に合ったエフェクトを重ねます（炎は着弾点から立ち上る火柱、氷は雪の結晶と冷気、雷は落雷、闇は闇の輪、風は竜巻 など）。素材は Effekseer 公式サンプル（CC0）です。
- `index.html` を直接開いたときは、どちらもオフになり、これまでの簡易版の動きで遊べます。

## 魔法図鑑

- 上部に「発動した魔法の数」「隠し魔法の発見数」「見つけた属性の数」を表示します。
- **タブ**: 「初級（2語）」「中級（3語）」「上級（4語）」「隠し魔法」の 4 つ。タブの数字は、その級で発動した魔法の数です（隠し魔法は隠し魔法のタブにだけ出ます）。
- **絞りこみと並べ替え**（初級・中級・上級）: 種類（すべて／攻撃／守り・回復・移動）と属性で絞りこめます。並びは「新しい順（初めて放った順）」「威力順（最大ダメージ。障壁は吸収量、再生は回復量）」「よく使う順」「名前順（読み）」から選べます。
- **お気に入り（★）**: 詳しい表示の「☆ お気に入りにする」を押すと、そのタブの一覧のいちばん上の「★ お気に入り」にまとまります。保存されます。
- **一覧**: 名前・属性・形と、最大ダメージ（障壁は吸収量、再生は回復量）。守り・回復・移動の魔法と、今の杖のスロットに入っている魔法には札が付きます。
- **詳しい表示**（上から順に）
  - 名前と読み、**ひとこと説明**（例:「炎の弾をまっすぐ撃つ。」）と**特徴の札**（例:「燃やす」「近くの的へ連鎖」「地形を壊す」）
  - 大事な数字 3 つ（最大ダメージ・消費 MP・待ち時間）と、ことばの並び
  - 放ち方: 「唱える」（読み）と「紋章」（重ねる紋章 → 左クリック）を 1 行ずつ
  - 「くわしく」（押すと開く）: 範囲・発動回数・最大貫通（壁）、くわしい説明、唱えるときの注意
  - 「スロット 1〜4」ボタンで、その魔法をスロットに入れられます（今入っている魔法も表示）。「工房でこの並びを開く」も使えます
- 未発見の隠し魔法は、ヒントを大きく表示します。
- 図鑑の枠の高さは固定しているので、絞りこみ・並べ替え・タブの切り替えで魔法の数が変わっても、一覧の位置は動きません（魔法が多いときは一覧の中でスクロールします）。
- ひとこと説明は、形ごとの短い文（魔弾なら「〇の弾をまっすぐ撃つ」）に属性の名前を入れて作り、特徴の札は属性と効果ごとに決めた短い言葉（燃やす・神速 など）を並べています。工房で放ったことのある魔法を選んだときにも、ひとこと説明が出ます。

## 判断したこと

- **ダンジョンの数値はこちらで決めた**（第26版）: 敵の強さ・経験値・お金・杖の値段・レベルアップで上がる量は、遊んでみて調整する前提の初めの値です（js/rpg.js にまとまっている）。
- **村から始める**（第26版）: ユーザーの希望どおり、神殿・杖の店・ダンジョンの入口がある村を作り、今までの練習場は村の門から行く場所にした。対戦が終わると村に戻る。
- **前の版のセーブデータ**（第26版）: レベルは Lv1・お金 100 G・杖は見習いの杖から始まる（ユーザーの希望どおり、杖は買って増やす）。発動した魔法・図鑑・隠し魔法の記録はそのまま残り、3 語・4 語の魔法は封印が解けるまで使えない。

- 画像はプログラムで生成していましたが、第30版から空・地面・壁・屋根・木・岩に素材を使っています（ダンジョンの洞窟・敵・魔法は今までどおりプログラムで作る）。効果音もプログラムで合成していましたが、第22版から音の素材（12 個）を重ねています（BGM は今までどおり合成）。
- **素材の組み込み方**（第30版）: index.html を直接開いても読めるように、画像は WebP の data URL、木と岩の形は数値を小さな整数に詰めて base64 にし、`js/asset-data.js` に入れています（元の素材は約 31MB → 約 1.5MB）。空の画像は下半分が地面なので上半分だけを使い、夜空はセピア色だったので青い夜空に色を寄せました。昼の空は夕方に近い金色の雲なので、日の光と霧の色もそれに合わせています。木と岩は InstancedMesh でまとめて描き、村では 120 本ほど置いても描く回数が増えすぎないようにしています。地面の模様は、地面のブロック（13m）ごとに整数回くり返して、境目で模様がずれないようにしました。
- **ダンジョンの岩は軽い版**（第31版）: 自然物ガチャの岩は 1 個 2,000〜3,000 三角形あり、壁ぞいに 300 個ほど並べると重くなるため、近い頂点を格子ごとに 1 つにまとめた軽い版（1 個 600 三角形ほど、面はかくかく）を作って使っています（js/assets.js の lowModel）。岩の前の面は当たり判定の壁より 0.3m 手前に出ていますが、体の幅より小さいので、めりこんで見えることはありません。岩が 1 マスの薄い壁の向こうへ突き抜けたり、通路の角で床にはみ出したりしないよう、置く場所に合わせて大きさを変えています。
- **敵の色**（第30版）: このゲームの描き方では、色の数値がそのままだと画面では白っぽく薄く出ます。参考の絵の色に合わせるため、敵の材質だけは色の数値を「画面で見える色」として扱うように変換しています。
- 保存はブラウザの localStorage（キー `magia-lab-v1`）。**ブラウザは開き方ごとに保存場所を分ける**ため、start.bat で開いたときと index.html を直接開いたときでは、記録（図鑑・スロット・最高記録）が別々になります。保存できない環境や、データが壊れていても初期状態で遊べます。
- へこむ地面は 10×10 のブロックに分け、クレーターができたブロックだけを細かい網目にしています。全体を細かくすると、性能の低いパソコンで描画が遅くなる（確認環境で 10fps まで低下）ためです。
- 最初から入っている 4 つの魔法も「まだ放っていない魔法」として扱い、名前は放つまで隠しています。
- 紋章の読み取りは、描いた線を 48 点に打ち直して大きさと位置をそろえ、33 個の手本との「点ごとのずれの平均」と「角の数のちがい」で一番近いものを選びます（ずれが大きすぎるときは読めないとする）。手ぶれ・傾き（±10°）・縦横のゆがみ（±25%）・描き始めのずれを加えた線で試したところ、正しく読めた割合は 99.9%（1200 本中 1199 本）、でたらめな線を紋章と読んだのは 3% でした。新しい 3 つの紋章は、最初に試したハート・盾形（五角形）がひし形とまちがわれやすかった（正解 96%）ため、門（Π）・e・C にしました。第20版の ω・↘・α は、20 個の候補を同じ方法で試し、ほかの紋章とまちがわれず、ほかの紋章を横取りもしないものから選びました（33 個合わせて 1320 本中 1319 本正解）。第22版の合成は、γ・2・h・P・6・b・Y・8・逆三角・Σ の 10 候補を同じ方法で試し、取りちがえのなかったものの中から、意味（2本の線が1本に合わさる）が合う Y を選びました（34 個合わせて 1360 本中 1359 本正解）。
- 紋章は手間がかかるぶん、杖を持っていても効果を下げない（無詠唱と同じ 100%）ことにしました。
- 詠唱の「多少の言い間違い」は、名前と、聞き取った文の中でいちばん近い部分の「2 文字ずつの組の重なり」（Dice 係数）が 0.6 以上なら同じとみなします（例: フレアキャノン → フレイキャノン は 0.67 で通る）。素手は、名前（読みか漢字）がそのまま文の中にあるときだけ通します。
- 守り・回復・移動は、新しい「形」として作りました。1番目の属性や 3・4番目の効果と自由に組み合わせられ、名前も今までと同じ決まりで付きます（盾・癒・転）。闘技場では自分の HP を回復する手段がないと押し切られやすいため、再生は 7 秒・障壁は 5 秒の待ち時間にしています。
- 自分の障壁は、内側から見る 3D の球にすると視界のじゃまになり、うすくすると見えなくなるため、画面のふちだけに網目を出す方法にしました。
- 闘技場は、練習場と同じ地面の上で、練習場の地形（壁・岩・木箱・石柱・貫通テスト場）をしまって入れ替えています。動ける範囲は壁の内側（半径 38.8m）です。客席の外の壁には当たり判定がないため、壁の上を越えて飛んだ魔法は、そのまま見えなくなります。
- **対戦のダメージは「撃った人の画面」で決めます。** 撃った人の画面で魔法が相手に当たったら、そのダメージを相手に送り、受けた人の画面で HP を減らします。通信の遅れがあっても、撃った人には「当てたのに当たらない」ことが起きにくい反面、受けた側からは「よけたつもりが当たった」ことがまれにあります（遊びの対戦では、こちらのほうが気持ちよく遊べるため）。
- 相手の魔法は、自分の画面では相手の位置と向きから同じ魔法を再現しています（見た目だけ。ダメージは上のとおり撃った人の画面で決まる）。そのため、壊れた地形や飛び散るがれきの細かい形は、画面ごとに少しずつちがいます。
- 渦・引力・事象の地平の「吸い寄せ」は、対戦の相手には効きません（相手の位置は相手の画面が決めるため）。吹き飛ばしは届きます。
- つなぐのに使うのは無料の STUN サーバーだけで、中継用の TURN サーバー（多くは有料）は使っていません。そのため、会社や学校の回線などでは、直接つながらないことがあります。PeerJS の初期設定には PeerJS の公開 TURN サーバーが入っていますが、試したところ中継だけではつながらなかった（25 秒待っても不可）ため、外しています。
- 合言葉でつなぐ方法は、アカウント登録も料金もいらない PeerJS の公開サーバーを選びました。公開サーバーが止まっているときに備えて、サーバーを使わない「コードでつなぐ」を予備として残しています。
- 合言葉は 32 のことば × 4 けたの数字（約 32 万通り）です。ゲームの版の番号（22）を部屋の番号に入れているので、版のちがうゲームどうしは混ざりません。同じ合言葉がほかで使用中なら、自動で作り直します。
- 杖のスロットの残り回数は保存しません（開き直すと全部の回数が戻ります）。以前の版のスロットの中身は「見習いの杖」に引き継ぎ、ほかの杖のスロットには最初から入っている魔法を入れておきます。
- 杖を持って唱えたときの「効果 30% ダウン」と素手の「50% アップ」は、ダメージ・燃焼などの継続ダメージにかかります。破壊の杖などの杖の威力倍率と重なります（例: 破壊の杖で唱えると 1.4×0.7 ≒ 0.98 倍）。
- 以前の版の保存データにある「登録しただけの魔法」は、放っていないので図鑑には引き継ぎません（スロット・発見済みの隠し魔法・最高記録は引き継ぎます）。
- **メニューは Tab**（第22版）: ブラウザは、マウスを固定しているときに Esc を押すと必ず固定を外すため、Esc を押したときはメニューではなく「一時停止中」の小さな画面を出し、そこから Tab でメニューへ移れるようにしました。工房や図鑑の中では、Tab は今までどおり項目の移動に使えます（メニューは開きません）。魔法工房は E キーだけで開きます。
- **召喚獣は的と同じ一覧に入れる**（第22版）: 弾・爆発・光線・連鎖などの当たり判定をそのまま使えるため。自分の召喚獣は自分の画面で動かして位置と HP を相手に送り、相手の画面では届いた位置に置くだけにしています。ダメージは今までの魔法と同じく「撃った人（召喚した人）の画面」で決まり、相手の召喚獣に当てたダメージは持ち主に送ります。
- **壁とドームは、立てた人の魔法を通す**（第22版）: 自分の壁で自分の魔法がふさがると使いにくいため。光線や貫通力のある弾でも、魔法の壁はつらぬけません（地形の壁とのちがい）。
- **ジャンプを少し高くした**（第22版、約 1.4m → 約 1.85m）: 地形の上に乗れるようにしたため、木箱・2段の石壁・小さめの岩に跳び乗れる高さにしました。3段の石壁や大きな岩には、飛翔や浮遊で乗れます。
- 対戦のやりとり（召喚獣・壁）が変わったので、ゲームの版の番号を 13 から 22 に上げました。第21版以前のゲームとは、同じ合言葉でも別の部屋になります。
- 音の素材は、index.html を直接開いたとき（file://）でも読めるように、mp3 を base64 にして JS ファイルに入れています（約 440KB）。素材が読めないときや解読が終わる前は、今までの合成した音だけが鳴ります。

## 公開サイトの更新

このフォルダーは GitHub のリポジトリ `gizora/magia-lab`（公開）とつながっていて、`main` ブランチがそのまま GitHub Pages で公開されます。`tests/` は `.gitignore` で除いています。
- 更新するときは、このフォルダーで `git add -A`・`git commit`・`git push` を行います。1分ほどで公開サイトに反映されます。
- このリポジトリのコミットには、GitHub の非公開用アドレス（noreply）を使う設定にしています（`git config user.email`）。個人のメールアドレスは公開されません。
